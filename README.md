# API Estudio de Tatuajes

API REST modular desarrollada con Node.js y Express para la administración de un estudio de tatuajes. Proyecto implementado siguiendo el flujo de trabajo GitFlow, revisiones de código cruzadas (Pull Requests) e Integración Continua (CI) automatizada con GitHub Actions.

## Integrantes y Roles
- **Miguel Llanten (Estudiante 1):** Configuración base, Pipeline CI y CRUD de Tatuadores.
- **Lenny Chilito (Estudiante 2):** CRUD de Clientes y revisiones técnicas de PRs.

## Requisitos Previos
- Node.js (v18 o superior)
- npm
